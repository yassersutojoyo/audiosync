# Clauses of docs/CAST_SPEC.md that a later stage of the sender implements,
# so no test covers them yet. One per line: the clause ID, a space, the reason.
# tests/spec_coverage.rs fails if a clause listed here gains a `// covers:`
# test, so this list only shrinks. "Partly done" names what already exists.

# Scope rules that need the host.
C2 One Cast device per stream: host stage.
C7 A Cast failure never stops other outputs: host stage (partly done: every session failure is a typed value returned to the host, and nothing in the sender touches other outputs).

# Connection.
C20 TLS 1.2 with ECDHE-RSA AES-GCM and CBC suites: the platform TLS stacks offer them, but native-tls can't pin a server suite in a test; G4 records what devices accept (partly done: TLS 1.2 minimum, a TLS 1.2-only server connects, handshake errors carry the TLS stack's reason).

# Formats.
C63 WAV and FLAC formats: FLAC encoder stage (partly done: live WAV with largest-value sizes at 44 100 and 48 000 Hz).
C84 WAV to FLAC fallback: FLAC encoder stage (partly done: LOAD_FAILED and IDLE with ERROR before PLAYING end the attempt with their reason).

# Timing: what the host does with the sender's numbers, and hardware.
C72 What the sender controls: host stage and G7 (partly done: WAV without encoder delay, the 2 s queue and its counters).
C73 No shared clock: host stage (the host never claims sample-accurate sync).
C74 Latency of seconds: hardware, G7.
C75 Growing latency: hardware, G7 (partly done: drops and rebuffers are counted, C79).
C76 Google group delay unreachable: host stage (nothing to send).
C77 Measured-offset output: host stage (per-speaker delay and the stored offset per device).
