Play a Windows PC's sound on AirPlay speakers

AudioSync is a free, open-source app that sends what your Windows 11 PC plays to AirPlay speakers, through its own AirPlay sender. The PC's own speakers, Bluetooth speakers and a Google Cast speaker can play along, in step with the AirPlay ones. It's a beta, so expect rough edges.

How it works

  • Pick a source: everything the PC plays (except AudioSync itself), one app, several apps, every app except the ones you pick, or an input like a mic or line in.
  • AirPlay speakers on your network show up under Connected Speakers. Turn one on and it joins the stream. Speakers that only do AirPlay 2 work with nothing to set up, up to 16 at once, and a stereo pair shows up as one row with one volume.
  • An Apple TV that asks for a code pairs the first time you turn it on: type the 4-digit code it shows and AudioSync remembers it. A speaker with a password asks for it when you turn it on.
  • Each speaker gets its own volume, next to a master volume and a 10-band EQ.

Why everything plays 1.75 seconds late

AirPlay speakers don't play audio the moment it arrives. AudioSync's sender tells them to play each bit of audio 1.75 seconds after it's sent, and they hold it in a buffer until then. That's how several AirPlay speakers end up playing the same moment.

While an AirPlay speaker is on, the PC's own speakers wait those 1.75 seconds too, plus whatever you set under AirPlay Delay, and every other output waits by its own delay on top of that. So they all stay in step. A Bluetooth speaker runs behind the rest, so give it a small negative delay (around −150 to −300 ms), or let Calibrate with Microphone set it. Turn the last AirPlay speaker off and the local outputs only line up with each other again, with no AirPlay wait.

That delay is fine for music, not for video or games. For video, a player with an audio delay setting, like mpv or VLC, can hold the picture back to match.

What doesn't work

  • Speakers that need Apple's MFi or FairPlay authentication, or any pairing other than the Apple TV code. They're listed with a note saying so, and AudioSync never connects to them.
  • Audio only. No video, photos or screen mirroring.
  • Windows 10 and older. On anything before Windows 11 the app says so and exits.
  • A network set to Public. Windows Firewall will probably block the search for speakers, so none show up. Set the network to Private, or allow AudioSync on Public networks in Windows Security.

Getting it

Download the zip for your PC, x64 or ARM64, from the latest release on GitHub. It's one exe with no installer: unzip it into a folder of its own and run it. The exe isn't signed, so SmartScreen may stop the first launch; click More info, then Run anyway. The README's Windows notes also have a one-line PowerShell install. After that it updates itself.

Want Google Cast speakers in the mix too? See AirPlay and Google Cast at the same time. On a Mac, there's multiroom with Bluetooth speakers. More about the app on the AudioSync home page.
